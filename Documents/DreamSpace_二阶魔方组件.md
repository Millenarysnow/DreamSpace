# 二阶魔方组件

`UDreamRubiksCubeComponent` 是可直接添加到 Actor 蓝图的二阶魔方组件，编辑器名称为 **Dream Rubiks Cube**。
它继承现有 `UDreamDragInteractionComponent`，复用 `IDreamInteractableInterface`、E 键交互、
手办捕获射线映射、拖动输入锁和退出清理逻辑。全部玩法由组件实现，不要求更换 Actor 父类。

支持八个角块的六面颜色、正负半层 90° 转动、平滑动画、打乱、撤销、复位、玩家步数和蓝图还原事件。
默认自动生成八个黑色主体和二十四张彩色贴纸，也可以绑定自己的八个独立角块模型。

## 最快使用方式

1. 将 `/Game/DreamInteraction/BP/BP_DreamRubiksCube` 拖入使用 `DreamPlayerController` 的关卡。
2. 将 Actor 放在玩家能够接近和瞄准的位置。默认总边长约 **102.5 cm**。
3. 进入 PIE。示例蓝图已开启 **开局打乱**；默认种子为 1337，同一配置每次开局题面一致。
4. 普通探索模式瞄准一个角块，**按住 E 并移动鼠标**；手办模式按 Tab 后，
   **在魔方画面中按住左键并拖动**。
5. 超过默认 5 cm 的局部面内阈值后转动一层 90°，耗时默认 0.25 秒。
   每次按住最多提交一步，松开再按住可继续转动。

示例蓝图只包含普通 Actor 根组件和本组件，没有另一套魔方蓝图玩法逻辑。
默认外观在 `BeginPlay` 创建；要在编辑器里预览，请在已放入关卡的 Actor 上选中魔方组件，
点击详情面板中的 **Rebuild Cube**。预览模型是临时生成件，不会把运行时状态写进地图。

也可以自行创建任意 Actor 蓝图：

1. 使用普通 SceneComponent 作为根，将根的 **Mobility** 设为 **Movable**。
2. 添加 **Dream Rubiks Cube**。不需要另加 Dream Pivot Point。
3. 保持 **生成默认外观** 开启，设置角块边长、间隙、中心偏移和开局打乱。
4. 将该蓝图放入关卡。修改外观配置后点击 **Rebuild Cube**，或重新进入 PIE。

如果 Actor 原本带有整颗魔方的单个显示网格，需要移除或隐藏该旧显示网格，避免它遮住生成的角块。
一个实际魔方 Actor 建议只安装本组件；现有控制器会优先选择该 Actor 上的第一个持续交互组件。

## 如何选层和方向

抓取必须首先命中某个角块的查询碰撞；原有控制器仍负责角色到机关/手办到真实世界的首个命中与遮挡。
组件随后锁定命中的角块身份和外侧面，并把持续鼠标射线投射到该面的无限延伸平面。

面内两个方向分别对应两种不同的转轴。设命中面的外法向为 `N`，主拖动方向为 `T`，
转轴及符号由 `N × T` 确定，正/负半层由被抓角块在该轴上的当前坐标确定。

例如在魔方 **-X 面** 抓住上半部，沿局部 **+Y** 拖动，则绕局部 **Z** 轴转动 **+Z 层**，方向为 -90°。
在同一位置沿 -Y 拖动则反向转动；沿上下方向拖动会选择另一根切向轴对应的半层。

- 轻微抖动不会立即转动；局部主方向超过 **拖动阈值** 才提交一步。
- 每次抓取只执行一个 90° 动作，不因为长按或快速移动而自动连续转多步。
- 松开交互键后已经提交的动画继续完成；新的操作在动画结束后才被接受。
- 没有达到阈值就松开，不改变逻辑状态，也不产生步数。
- 鼠标移出魔方轮廓仍可拖动，不必持续命中模型；移出手办显示面时暂停。
- 再进入手办显示面的首帧只重新采样，不把跨边界位移算作转动。
- 相机变化通过现有控制器的射线重采样消除，不会把镜头自身运动当成玩家拖动。
- 按住 E 时沿用临时光标和移动/视角锁；手办观察、右键展示旋转仍由原控制器管理。

## 外观和调参

| 配置 | 默认值 | 用途 |
| --- | --- | --- |
| 魔方中心偏移 | (0,0,0) | 根组件局部空间中的旋转中心 |
| 角块边长 | 50 cm | 默认主体尺寸，总边长为 `2 × 边长 + 间隙` |
| 角块间隙 | 2.5 cm | 两半层之间的黑色缝隙 |
| 生成默认外观 | 开启 | 自动创建八角块和贴纸 |
| 主体网格 | Engine BasicShapes/Cube | 按 Bounds 中心与尺寸缩放，不要求模型原点居中 |
| 颜色材质 | Engine BasicShapeMaterial | 主体和贴纸共用可调色材质 |
| 颜色参数名称 | Color | 自定义材质应有对应 Vector 参数 |
| 贴纸边距 | 3 cm | 每张贴纸外侧留黑宽度 |
| 90° 转动时长 | 0.25 s | 0 为立即完成 |
| 拖动阈值 | 5 cm | 沿当前面的局部主方向累计位移阈值 |
| 拖动灵敏度 | 1 | 沿用父类输入增益；0 暂停拖动 |
| 开局打乱 | 组件默认关闭，示例开启 | BeginPlay 后生成待解题面 |
| 打乱步数 / 种子 | 20 / 1337 | 固定种子可复现关卡题面 |

默认配色为 +X 红、-X 橙、+Y 绿、-Y 蓝、+Z 白、-Z 黄。
Actor 整体平移、旋转和正缩放可以用于关卡摆放，魔方轴和交互平面随整体变换。
修改中心、尺寸、绑定或材质后需重建；根组件的零缩放和镜像缩放会被拒绝。

默认主体使用可查询碰撞，阻挡现有 Visibility 交互射线；贴纸不参与碰撞，避免薄片影响拾取。
内部层转动直接改变子组件姿态，不借用整个 Actor 的平台旋转/角色重力跟随。
本组件不做外部障碍阻挡与回弹；为旋转的四个角块留出运动空间。

## 使用自己的八个角块模型

在同一 Actor 中准备八个 **Movable** 角块根组件，直接挂在 Actor 根下；
每个角块根下面可以有多个网格、碰撞盒或装饰组件。角块中心应对称地放在魔方中心的八个角，
先把所有颜色摆成六面同色的还原姿态。

关闭 **生成默认外观**，在 **自定义角块组件（8 项）** 中用组件选择器按以下顺序绑定：

| 索引 | 根局部坐标相对魔方中心的符号 |
| --- | --- |
| 0 | X- Y- Z- |
| 1 | X- Y- Z+ |
| 2 | X- Y+ Z- |
| 3 | X- Y+ Z+ |
| 4 | X+ Y- Z- |
| 5 | X+ Y- Z+ |
| 6 | X+ Y+ Z- |
| 7 | X+ Y+ Z+ |

绑定后点击 **Rebuild Cube**。组件会记录各角块的初始相对变换，转动时保留作者设置的模型预旋转和缩放。
同一组件不能被重复绑定；根、角块及其子网格不得开启绝对世界变换或自行模拟物理。
角块须有简单/复杂查询碰撞并阻挡控制器的交互通道，纯视觉网格无法被玩家抓取。

现有 `/Game/0_/Blueprints/Rubiks` 资源可以作为模型整理的参考。
本组件不自动解析旧蓝图中的 ChildActor、Timeline、输入动作或 GAS；
若旧资源是一整颗合并网格，需要拆成八个角块，或使用默认生成外观。

自定义模型的颜色不通过 GPU 回读或材质名称推断，组件以绑定顺序和初始还原姿态作为颜色身份约定。
因此自定义八角块的初始颜色摆放需要由模型作者确认。

## 蓝图调用和事件

| 入口 | 作用 |
| --- | --- |
| `RotateLayer(Axis, LayerSign, Direction, bAnimate)` | 请求局部 X/Y/Z 正/负半层转动，正负号只接受 -1 或 +1 |
| `ResetCube()` | 恢复初始姿态，清除玩家步数和历史 |
| `ShuffleCube(NumMoves, Seed)` | 先复位再立即打乱，步数限制到 1~200；不记玩家步数 |
| `UndoLastMove(bAnimate)` | 逆转最后一个玩家动作，完成后从历史移除 |
| `IsSolved()` / `IsTurning()` | 查询还原和动画状态；动画期间 IsSolved 为 false |
| `GetMoveCount()` | 当前玩家动作历史长度，撤销一步减一 |
| `GetCornerCoordinate(Index)` | 固定角块身份的当前整数格坐标 |
| `GetCornerComponent(Index)` | 对应角块根组件，供蓝图效果或调试使用 |
| `RebuildCube()` | 根据当前配置重建模型和初始状态，提供编辑器按钮 |

调用返回 `false` 表示没有执行动作，例如组件停用、非法层号、配置无效或转动/抓取期间请求另一动作。
转动、复位、打乱和撤销不排队；蓝图需要等待动画或拖动结束再请求下一动作。
瞬时转动仍提交完全相同的整数状态和事件，打乱只在最终题面完成后通知还原状态变化。

- **On Turn Completed**：每次玩家转动/撤销提交后广播 Axis、LayerSign、Direction，可绑定音效。
- **On Solved State Changed**：六面同色状态变化时广播布尔值；复位与打乱也通知，可绑定指示灯。
- **On Cube Solved**：玩家通过转动或撤销从未还原进入还原时触发，可连接开门、奖励或提示。
  开局完整状态、`ResetCube` 和 `ShuffleCube` 不触发通关事件。

状态和模型在广播前已完整提交；事件广播期间再次修改魔方会返回 false。
需要在通关回调中启动下一题时，可以用蓝图的下一帧延迟后调用 `ShuffleCube`。

还原判断检查六面各有四张同色贴纸，兼顾角块排列和朝向。
二阶魔方没有固定中心块，整颗魔方换方向后仍六面同色的状态也算还原。
步数、撤销历史和题面状态目前保存在本次组件运行会话中。

## 状态与生命周期

逻辑角块位置和三个朝向基向量使用 `FIntVector`。90° 旋转通过交换分量和符号实现，
不使用插值角度反推角块格子。视觉朝向每步从初始姿态与整数基向量计算，避免累计浮点漂移。

动画中只改变四个角块的模型变换，结束后一次性提交逻辑与历史；
主动停用组件、角块引用失效或非法根变换会取消未提交动画并恢复上一步合法姿态。
松手、控制器结束抓取或切换观察模式不取消已经确定的 90° 动作。
移除组件会清理它自动生成的模型和碰撞，保留用户绑定的自定义角块。

控制台 `dream.DebugPivots 1` 可显示八个角块中心，正在转动的四块为黄色，旋转轴为品红色。
手办射线诊断继续使用 `dream.DebugMiniatureInteraction 1`。
