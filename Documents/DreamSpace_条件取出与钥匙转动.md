# 条件取出与钥匙转动

这两个功能都通过原有交互组件的可选配置启用：取出范围留空、钥匙条件不勾选时，保留已有交互行为。
新增配置、重叠查询、输入选择、反馈生命周期及测试均有中文注释。

## 手办取出许可范围

在 `Dream Miniature Extractable` 的 **手办取出 → 条件 → 允许取出的重叠碰撞体（可选）** 选择一个碰撞组件。
组件引用允许选择同一 Actor 或同关卡中其它 Actor 的碰撞体；外部范围请在关卡中的 Actor 实例上指定。
建议在目标位置摆一个独立 Actor，添加 Box / Sphere / Capsule 碰撞作为固定许可区域。

1. 保留物体上的 `Dream Draggable` 和 `Dream Pivot Point`，根组件设为 **Movable**，按原方式配置运动轴和距离。
2. 范围碰撞体开启 **Query Only** 或 **Query and Physics**；物体也要有开启 Query 的有效简单碰撞。
3. 范围只作为许可区域时，可将碰撞响应全部设为 **Ignore**，避免它阻挡自由拖动、玩家或手办射线。
   无需开启 **Generate Overlap Events**，也无需为物体额外设置 Overlap 响应。
4. 指定引用留空时，仍然可以在任意位置取出；填错、失效或关闭 Query 时，不会退回无限制取出。

手办模式按下左键时，以双方实际简单碰撞形状判断是否相交；不是检查 Actor 原点，也不是检查世界 AABB。
所属 Actor 任意有效查询碰撞组件与指定范围相交即可，包括无碰撞根组件下的网格或碰撞盒。
如果范围挂在同一 Actor 上，它自身不算“与自己重叠”的证据，但可以与该 Actor 的其它碰撞体比较。

- 未相交：开始现有自由拖动，源模型保持可见，不生成掉落物预览。
- 已相交：取出组件优先，源模型隐藏，开始现有面外拖出流程，自由拖动不同时启动。
- 一次按住期间保持选定行为；自由拖动把物体移入范围后，**先松开，再重新按住左键**即可取出。
- 取出开始后不重复检查范围，因为源 Actor 已主动关闭碰撞；面内松开或取消仍恢复原状态。
- 正常探索中的 E 自由拖动不受这个取出范围限制。

蓝图 `CanExtractAtCurrentLocation()` 可查询当前位置是否允许选择取出；`BeginExtract()` 也执行同一检查，
范围外直接调用不会生成预览或隐藏物体。

## 交互转动需要钥匙

实际转动组件是 `Dream Rotatable`（`UDreamRotatableComponent`）；`EDreamPivotRotationAxis` 是其 X/Y/Z 轴向枚举。
在转动组件的 **可转动 → 钥匙 → 交互需要钥匙** 勾选即可启用。
继续按原方式配置枢轴、轴向、步进角和转动时长。

- 世界 E 与手办左键均检查本次操作者的 `ADreamCharacter.bHasKey`。
- 没有钥匙：不执行正常步进，只绕配置枢轴做约 **0.35 秒、最大 2°** 的衰减往复晃动，然后精确恢复原变换。
- HUD 在视口正中央显示 **需要钥匙**，默认 **2 秒**，按文字实际宽高居中并带阴影，暂时隐藏准星。
- 反复交互可以刷新文字时长，不叠加或重启正在播放的晃动；晃动结束后可以再次尝试。
- 通过现有钥匙拾取流程获得钥匙后，即可执行原有正常转动；**不消耗钥匙**，也不添加另一份机关解锁状态。
- 拾取成功立即清除旧的“需要钥匙”文字，避免拒绝提示覆盖“已获得钥匙”。

拒绝反馈使用独立于正常步进的时长，即使 `RotationDuration = 0` 也会显示轻微晃动。
开启 **运动考虑碰撞** 时，反馈也沿小步检查完整晃动曲线；紧贴阻挡物时可能很早停止并回正，文字仍显示。
开启站立角色重力跟随时，仍站在机关上的角色随实际晃动往返，回正后恢复对应位置、胶囊朝向、重力与视角。
中途离开的角色继续遵循原有“保留离开时重力”的约定。
停用、动态移除组件或关卡退出会清理尚未结束的反馈，避免机关留在偏移姿态。

蓝图/C++ 的 `TriggerRotation` 增加可选的 **Interactor** 参数：开启钥匙条件时，传入实际交互的 DreamCharacter。
使用 `OnInteracted` 接口或默认玩家控制器时自动传入，无需额外连线。
直接调用时空参数、普通 Actor 或跨世界角色均不能绕过检查；未开启钥匙条件时旧无参数调用仍有效。
