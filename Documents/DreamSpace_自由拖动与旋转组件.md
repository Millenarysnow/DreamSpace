# 自由拖动与旋转组件

新增两个可以直接添加到任意机关 Actor 的组件：

| 编辑器组件名称 | C++ 类 | 行为 |
|---|---|---|
| Dream Draggable | `UDreamDraggableComponent` | 沿枢轴局部 X/Y/Z 中的一根轴，在距离范围内连续平移 |
| Dream Drag Rotatable | `UDreamDragRotatableComponent` | 绕枢轴局部 X/Y/Z 中的一根轴，在角度范围内连续旋转 |

两个组件均继承 `UDreamDragInteractionComponent`，实现现有的 `IDreamInteractableInterface`。
它们直接移动所属 Actor；无需新增输入资产、Actor 蓝图父类或物理约束。

## 关卡配置

1. 在机关 Actor 上添加 `Dream Pivot Point`，设置它的位置和朝向。
2. 添加其中一个自由交互组件，在 **自由交互 → 枢轴** 选择枢轴点组件和运动轴。
   与现有组件一样，枢轴引用留空时使用同一 Actor 上的第一个枢轴；多枢轴时应明确选择。
3. Actor 根组件和移动碰撞组件设为 **Movable**。
4. 设置 **自由拖动 → 范围** 的负向/正向距离，或 **自由旋转 → 范围** 的负向/正向角度。
   两个范围值都填写非负数；0 表示对应方向没有行程。
5. 需要阻挡时，在 **自由交互 → 碰撞** 开启 **运动考虑碰撞**。默认关闭。
6. 旋转平台需要改变玩家重力时，在 **自由旋转 → 重力** 开启 **站立角色重力跟随旋转**。默认关闭。

范围零点和轴向在组件 `BeginPlay` 固定。动态添加组件会在第一次调用时补做初始化。
枢轴随所属 Actor 一起移动不会改变已经固定的范围，不会出现越拖越远的零点漂移。
组件选择器、范围、碰撞、重力等配置可在蓝图默认值或关卡实例中设置，新增代码包含中文注释。

### 平移零点

平移的 0 cm 对应枢轴的开局世界位置；所选轴在世界中的方向由枢轴开局朝向确定。
Actor 原点与轴线之间的初始垂直偏移会被保留，不会抓取后突然吸附到枢轴轴线上。

例如枢轴局部 X 指向世界 +Y，负向范围 50、正向范围 200，则 Actor 的轴向坐标受限于
`[-50, 200]` cm。移动不改变 Actor 的旋转或缩放。

初始摆放应位于范围内。若初始坐标已经越界，开局和抓取只记录真实位置；第一次非零拖动输入
或蓝图位置请求才会按配置范围限制，开启碰撞时仍检查该次纠正的完整路径。

### 旋转零姿态

开局 Actor 姿态是 0°，枢轴位置是公转中心，所选局部轴是世界转轴。
偏心枢轴同时产生 Actor 的公转和自转；枢轴在 Actor 原点上时只有自转。

正负角度分别限定零姿态两侧的行程。角度保留累计值，可以设置超过 180°、360°的范围。
从 0° 请求 +270° 会经过正向完整 270°路径，碰撞检测也沿这条路径推进。
鼠标径向跨越 +179° / -179° 时角度连续，不会突然翻转近一整圈。

## 玩家输入

- 普通探索模式：从相机中心瞄准机关，**按住 E** 后移动鼠标；松开 E 停在当前位置。
  抓取期间临时显示鼠标，暂停角色移动输入、转视角和滚轮缩放，结束后恢复。
- 手办模式：按 Tab 显示光标，在手办中**按住左键**抓取机关，再拖动光标；松开左键结束。
  持续拖动使用表现组件映射出的 SceneCapture 世界射线，与已有手办点击投影一致。
- 抓取后无需再次命中机关轮廓，移出轮廓仍可继续拖动。移出手办显示面时暂停输入；
  再进入时首帧只重建鼠标采样，避免物体跳变。
- 松开后不回弹、不惯性滑动、不按固定步长吸附。重新抓取从当前实际位置或角度继续。
- 到达范围端点或碰撞受阻时不会积累未完成的输入，反向拖动立即响应。
- 模式切换、按键取消、目标组件销毁、组件停用和失去操控角色都会清理持续交互及输入锁。

常规视角使用几何解算：平移取鼠标世界射线与运动轴的最近点，旋转取射线与旋转平面的交点径向。
抓取时视线几乎平行运动轴、平行旋转平面，或正对枢轴中心时，改用屏幕增量：向右/向上为正向。
可在 **输入** 高级属性中调整退化视角的厘米/像素或度/像素灵敏度；普通 **拖动灵敏度** 同时作用于两种输入。

平台重力跟随可能带动玩家相机。控制器在当前帧相同投影下比较上一与当前鼠标位置的射线，
避免把相机自身变化误当作拖动输入，鼠标静止时不会形成持续旋转反馈。

已有步进组件继续响应单次 E / 手办左键点击。若一个 Actor 同时挂有自由和步进组件，
控制器优先选择第一个自由组件，只运行一个持续行为；推荐每个实际移动 Actor 配置一个运动交互组件。

## 碰撞与重力

开启运动碰撞时，移动件须启用 **Query** 碰撞，并与障碍物互相设置 **Block**。
根组件可以是无碰撞 SceneComponent，随根移动的附属网格/碰撞盒都会参加查询。

平移每次请求检查完整扫掠，受阻停在接触面之前。旋转沿带符号角度细分：每步最多 2°，
并将最远碰撞点每步弧长限制到约 2 cm。遇阻后停在上一安全角度，可立即反向离开。
与步进组件不同，自由组件没有“本次完整步进失败”的回弹逻辑。

重力跟随只影响真正站在所属 Actor 移动碰撞体上的 Character，沿每段实际运动同步改变位置、
胶囊朝向、当前世界重力、速度和控制器视角。走下或跳离后停止跟随，保留最后世界重力方向。
开启碰撞与重力时会分别检查平台和站立角色的路径，并忽略这批同步物体彼此之间的碰撞。
角色头部遇到外部障碍也会阻止平台继续转动。

这套重力搬运由自由旋转和现有 `Dream Rotatable` 共用 `DreamRotationSupport`，
原有步进旋转的默认行为和受阻回弹策略由原组件继续管理。
详细重力约定见 [旋转组件角色重力](DreamSpace_旋转组件角色重力.md)。

旋转查询仍是离散子步，极薄障碍或没有可查询简单碰撞的网格需要合适的碰撞盒/凸体。
不要同时用另一个组件、物理模拟或蓝图 Timeline 修改同一 Actor 的变换。

## 蓝图调用与调试

| 入口 | 用途 |
|---|---|
| `BeginDrag(Interactor, RayOrigin, RayDirection)` | 开始抓取，只采样，不移动 |
| `UpdateDrag(RayOrigin, RayDirection, PointerDelta)` | 发送当前世界射线；像素增量 X 向右、Y 向下 |
| `EndDrag()` / `IsDragging()` | 结束或查询抓取状态 |
| `SetTranslation(cm)` / `GetCurrentTranslation()` | 请求或查询实际平移坐标 |
| `SetRotationAngle(degrees)` / `GetCurrentAngleDegrees()` | 请求或查询实际累计旋转角度 |
| `ReinitializeReference()` | 非拖动期间从当前枢轴和 Actor 姿态重建范围参考 |

蓝图直接设置距离/角度也遵守范围与碰撞，返回值是实际到达值。
直接使用交互接口时只开始采样；自定义控制器仍需持续发送 `UpdateDrag` 并负责 `EndDrag`。
运行时更换运动轴或参考枢轴后调用 `ReinitializeReference()`；旋转会把当前姿态定义为新零度。

控制台 `dream.DebugPivots 1` 显示固定平移范围、端点和旋转角度扇形；红色为负向，绿色为正向，
青色为当前位置/角度，品红色为旋转轴。`dream.DebugPivots 0` 关闭。
