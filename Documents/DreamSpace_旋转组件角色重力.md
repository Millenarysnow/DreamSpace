# 旋转组件的角色重力跟随

`Dream Rotatable` 组件的详情面板新增 **可转动 → 重力 → 站立角色重力跟随旋转**。
对应 C++ / 蓝图属性为 `bRotateStandingCharacterGravity`，默认关闭，可在蓝图中运行时修改。

## 配置

1. 在机关 Actor 上选中 `Dream Rotatable`，开启 **站立角色重力跟随旋转**。
2. 按原有方式选择枢轴点、X/Y/Z 轴、步进角和旋转时长；不需要额外重力体积或角色附着。
3. 平台根组件和随根运动的碰撞组件需为 **Movable**，平台需启用查询碰撞并阻挡 **Pawn**，
   让 `CharacterMovement` 能正常落地并把平台碰撞组件识别为角色的底座。
4. 玩家使用项目当前的 `ADreamCharacter` / `ADreamPlayerController`，已有重力平面移动和相机控制会继续生效。

## 行为

- 只影响当前站在所属 Actor 根组件或其附属碰撞组件上的 `Character`。侧面经过、空中悬停、
  正在下落或跳离的角色不参与；支持多个站立角色，中途登上也会从登上时开始跟随。
- 角色的世界位置、胶囊朝向、重力方向、移动速度和控制器视角随平台每次实际旋转同步改变。
  枢轴偏离 Actor 原点时，角色也会随平台公转，保持与站立表面的相对位置。
- 重力使用角色**当前世界方向**累积旋转，不预设角色原来一定受到世界 `-Z` 重力。
  例如世界 X 轴正转 90°，角色原重力 `(0, 0, -1)` 变为 `(0, 1, 0)`。
  若枢轴本身有朝向，则以枢轴局部 X 在世界中的真实方向为旋转轴。
- 转成墙面或天花板后仍可站立、移动和跳跃。走下平台或跳离后停止平台跟随，
  **重力方向不恢复**；离开的角色继续沿最后的世界重力方向下落，原平台后续转动不会再改变它。
- 关闭开关也不重置已经改变的重力。需要显式恢复时，可对角色的 `CharacterMovement`
  调用 `SetGravityDirection((0, 0, -1))`；本组件不自动执行恢复。
- 平台静止时不修改角色重力；走上一个已旋转的平台也不会瞬间重设重力。
  只有角色成功站立后，该平台后续的实际转动才会继续旋转它的重力。

这里改变的是受影响角色的**世界空间重力方向**，不会修改物理世界的重力、其他角色或物理刚体。

## 与运动碰撞配合

重力开关与 **运动考虑碰撞** 独立。关闭运动碰撞时继续使用原有的无碰撞旋转规则。

两者同时开启时，碰撞子步会同时检查平台及站立角色的路径，并排除这批同步运动物体之间的碰撞。
这样站立角色不会误挡平台，但角色头顶或身体遇到外部阻挡时，平台仍会停在上一安全姿态并回弹。
回弹时仍站在平台上的角色会同步转回；中途离开的角色保留离开时重力，不随原平台复位。
旋转时长为 0 时也支持完整路径检查及受阻后的立即复位。

底层沿用现有的旋转离散子步查询。极薄障碍、复杂网格或运行中进入回程路径的障碍，
仍遵循 [交互组件运动碰撞](DreamSpace_交互组件运动碰撞.md) 中的精度与路径限制。

## 实现与验证

`UDreamRotatableComponent` 在每个运动帧根据 `GetMovementBaseObject()` 和 `IsMovingOnGround()` 收集站立角色。
普通插值、瞬时转动、碰撞子步和回弹共用 `ApplyActorTransform()`，按平台实际姿态差旋转角色。
搬运完成后调用 `SaveBaseLocation()`，防止移动组件再次应用相同底座位移或重复旋转相机，
并强制下一次地面查询使用新重力下的碰撞数据。

自动化套件：`DreamSpace.Puzzle.RotationGravity`。在瞬时物理世界中生成真实 `ADreamCharacter`，覆盖：

- 默认关闭兼容旧行为。
- 60 帧平滑旋转、胶囊/相机对齐，以及不同更新顺序下没有重复底座搬运。
- 绕 X 轴转 90° 后实际行走并离开平台，保持新方向重力并沿该方向下落。
- 连续四次瞬时旋转经过墙面、天花板并回到初始重力，包含偏心枢轴及开启碰撞。
- 通过实际跳跃输入离开倾斜平台；空中保留底座时仍停止跟随，邻近角色不受影响。
- 角色上半身先于平台受阻时同步回弹；0 秒旋转受阻时位置、朝向、重力同步复位。

测试不保存或修改关卡和蓝图。可视手感仍需在目标关卡中开启开关后用 PIE 验收。

本次验证：UE5.8 的 `DreamSpaceEditor Win64 Development` 和 `DreamSpace Win64 Development` 编译成功；
完整 `DreamSpace` 套件的 18 项测试通过，其中包含新增的 6 项重力测试。
